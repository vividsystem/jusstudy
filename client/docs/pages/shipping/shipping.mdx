# Shipping

## What does shipping mean?
Shipping means making your project public for people to see and use. Once this gets approved, you will get pages which you can
use to buy prizes from the shop, or fund hardware builds. Something that you ship must be publically accessable and play/usable it must be as a public git repo (GitHub, GitLab, etc.) or a public website. If you are making a hardware project, you will need to have a video of your project working and a public git repo with the code and files for your project.

## What do I need?

#### Readme.md
You need to have a readme.md file with information about your project, how to run it and what it is.
It should have:
- A short description of your project (one line is enough)
- Why you made it
- How to run it (if applicable)
- Photos/Demo
#### File organisation
You can't just have a bunch of files in a folder, they need to be organised in a way that makes sense and is easy to understand.
#### Usability
Your project has to actually work and be able to run on the device it is intended for. If it is a website, it should be able to run on a browser, if it is a hardware project, it should be able to run on the hardware it is intended for. If something is incomplete, say so in the readme, so the reviewers don't have to find it themselves.
#### AI Disclosure
You are allowed to use AI tools as a TOOL to help you with your project, but you must disclose it in your readme. You should NOT write the whole thing with AI, we can tell and it can get you banned.
If you are having trouble with your project, you can ask in the slack channel for help or even just google it, google is your best friend.
#### License
It must have a license file in the root of your project. You can use [choosealicense.com](https://choosealicense.com/) to find a license that works for you. If you don't know what license to use, you can use the MIT license, which is a permissive license that allows others to use your code as long as they give you credit.
